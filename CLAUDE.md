## Project Overview

PickleIQ is an Angular 19 application for pickleball skill assessment, providing evaluation forms for skill levels 2.0-5.0, training videos, and equipment recommendations.

## Common Commands

### Development

```bash
npm start                 # Start dev server with SSL and proxy config
npm run build            # Production build with environment setup
npm test                 # Run unit tests with Karma/Jasmine
npm run test:ci          # CI tests with linting
npm run e2e              # End-to-end tests with Protractor
npm run lint             # Full linting: TypeScript, SCSS, and HTML
npm run prettier         # Format all code
npm run generate         # Angular CLI generator shortcut
```

### Specific Linting

```bash
ng lint                                          # TypeScript linting
stylelint "src/**/*.scss" --syntax scss        # SCSS linting
htmlhint "src" --config .htmlhintrc            # HTML linting
```

### Other Tools

```bash

npm run docs                   # Start documentation server

```

## Architecture Overview

### Core Structure

- **@core/**: Core module with auth, HTTP interceptors, logger, and guards
- **@shared/**: Reusable components, models, classes, and utilities
- **features/**: Feature modules with lazy loading
  - **rating/**: Main skill assessment system (dashboard, evaluation forms, report cards)
  - **training/**: YouTube integration for training videos
  - **shop/**: Equipment recommendations with Amazon integration
- **shell/**: Application shell and navigation

### Path Aliases (tsconfig.json)

```typescript
"@app/*": ["src/app/*"]
"@core": ["src/app/@core"]
"@core/*": ["src/app/@core/*"]
"@shared": ["src/app/@shared"]
"@shared/*": ["src/app/@shared/*"]
"@env/*": ["src/environments/*"]
```

### Key Technologies

- Angular 19.2.10 with standalone components support
- Bootstrap 5.2.3 + ng-bootstrap for UI
- NGX Formly for dynamic forms (A/B/C/D grading system)
- OAuth2/OIDC authentication (angular-oauth2-oidc)
- Google Sheets API for skill data (ng-google-sheets-db)
- YouTube API for training videos
- Service Worker PWA support

## Data Models & APIs

### Assessment Flow

1. **Dashboard** (`/rating`) - skill level selection
2. **Evaluation** (`/rating/level{XX}`) - dynamic forms for levels 20,25,30,35,40,45,50
3. **Report Card** (`/rating/reportcard`) - results with print functionality

### External APIs

- **Google Sheets**: Skill definitions and grading criteria
  - API Key: `googleSheet.apiKey` in environment
  - Sheet ID: `googleSheet.spreadsheetId`
  - Worksheets: 'Skills' and 'Grades'
- **YouTube**: Training video search
  - API Key: `youtube.apiKey` in environment
  - Max results: 10 per search

### Authentication

OAuth2/OIDC configured for optional user authentication:

- Client ID: 'MickleballClient'
- Code flow with PKCE
- Identity server: configurable in environment

## Environment Configuration

### Required Setup

Environment files use `.env.ts` generated by `npm run write:env`. Key configurations:

```typescript
// Key environment variables to configure:

  apiKey: 'your-youtube-api-key'

oidc: {
  issuer: 'your-identity-server',
  clientId: 'your-client-id'
}
```

## Development Guidelines

### Code Style

- TypeScript with strict mode and `noImplicitAny: true`
- SCSS for styling (not CSS)
- Prettier formatting with pre-commit hooks (Husky)
- Component prefix: `app-`

### Forms & UI

- Use NGX Formly for dynamic forms
- Bootstrap classes for styling
- Reactive forms with RxWeb validators
- FontAwesome icons via angular-fontawesome

### HTTP & State

- API calls through services with interceptors for error handling and API prefixing
- RxJS observables for state management (no NgRx)
- HTTP loader integration with ng-http-loader

### Testing

- Unit tests: Jasmine + Karma
- E2E tests: Protractor (consider upgrading to Cypress)
- CI configuration includes linting + testing

## Build & Deployment

### SSL Development

Development server runs with SSL certificates in `src/assets/cert/`. Accept browser security warnings for `https://localhost:4200`.

### Production Builds

- Service Worker enabled for PWA functionality
- Bundle budgets: 2MB warning, 5MB error for initial bundles
- File replacements swap development environment for production

### Deployment Targets

- **GitHub Pages**: `ng deploy --dir=dist/browser --base-href="/pickleiq/"`
- **Azure**: CI/CD pipeline configured in `azure-pipelines.yml`
- **Service Worker**: Caching strategies via `ngsw-config.json`
